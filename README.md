# smileDetector

smileDetector — детектор рта. Программа берёт видео с веб-камеры, находит в кадре рот
и определяет, открыт он или закрыт. Найденная область обводится рамкой с подписью класса
(`open` / `close`) и уверенностью модели в процентах. Больше приложение ничего не делает.

Детекция работает на собственной модели YOLOv8, обученной на размеченном датасете и
экспортированной в ONNX. Инференс выполняется на C++ через ONNX Runtime.

## Пайплайн

1. **Разметка данных** — датасет размечен в [Roboflow](https://roboflow.com) (два класса: `open`, `close`)
   и выгружен в формате YOLOv8.
2. **Обучение** — `train_model.ipynb` (Google Colab, GPU): дообучение YOLOv8 на этом датасете.
3. **Экспорт** — из ноутбука модель экспортируется в ONNX (`model.export(format="onnx")`),
   результат — `Resources/best.onnx`.
4. **Инференс на C++** (`main.cpp`):
   - **letterbox-препроцессинг** — кадр масштабируется с сохранением пропорций до 640×640,
     поля заливаются серым (114, 114, 114);
   - кадр переводится в blob NCHW, RGB, значения нормируются в диапазон 0..1
     (`cv::dnn::blobFromImage`), и подаётся в сессию ONNX Runtime (вход `images`, выход `output0`);
   - **разбор выхода YOLOv8** — тензор `(1, 6, 8400)`: для каждого из 8400 кандидатов читаются
     координаты бокса `xc, yc, w, h` и оценки двух классов, отбираются кандидаты с оценкой выше 0.4;
   - координаты боксов пересчитываются обратно из letterbox-кадра в координаты исходного кадра;
   - **NMS** — `cv::dnn::NMSBoxes` (порог оценки 0.30, порог IoU 0.45) убирает дублирующиеся рамки;
   - оставшиеся рамки рисуются на кадре и показываются в окне.

## Модель

Модель и тестовые картинки лежат в `Resources/` и копируются в каталог сборки средствами CMake:

- `best.onnx` — модель для инференса на C++;
- `best.pt` — веса YOLOv8 после обучения, из них сделан экспорт в ONNX;
- `*.jpg`, `*.jpeg` — тестовые изображения.

Параметры обучения из `train_model.ipynb`: YOLOv8, 100 эпох, размер изображения 640, batch 32.
Модель после fuse — 72 слоя, 11 126 358 параметров, 28.4 GFLOPs; экспортированный ONNX весит 42.7 МБ.
Метрик качества (mAP, precision, recall) в сохранённом выводе ноутбука не осталось —
сохранился только лог экспорта, поэтому привести их здесь нельзя.

Чтобы обучить модель заново, нужно открыть `train_model.ipynb` в Google Colab и подставить
свой ключ API Roboflow вместо заглушки `YOUR_ROBOFLOW_API_KEY`.

## Зависимости

- C++17, CMake 3.10+
- [OpenCV](https://opencv.org) — захват видео с камеры, препроцессинг, NMS, отрисовка
- [ONNX Runtime](https://onnxruntime.ai) — инференс модели
- рабочая веб-камера

На macOS зависимости ставятся через Homebrew:

	brew install cmake opencv onnxruntime

## Сборка и запуск

	git clone https://github.com/triplq/smileDetector.git
	cd smileDetector

	mkdir build && cd build
	cmake ..
	make

	./smileDetector

CMake копирует `Resources/` в каталог сборки, поэтому запускать программу нужно из него —
модель ищется по пути `./Resources/best.onnx`.

Выход из программы — клавиша `q` в окне с видео. При первом запуске macOS спросит
разрешение на доступ к камере.

## Вспомогательные скрипты

В `experiments/` лежат два скрипта, которые в сборку не входят:

- `image_inference.cpp` — тот же инференс, но по одной картинке вместо видео с камеры;
  использовался для отладки разбора выхода модели;
- `inspect_onnx.py` — печатает имена входов и выходов `best.onnx` (нужны для `Session::Run`).
